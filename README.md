# Juniper Café Receipt System

A small Python café management experiment developed while studying
Fundamentals of Programming (DIT014).

## About the Project

The project started from Lab 03 of DIT014, which focuses on user input,
strings, type conversion, and output formatting.

I am extending the original lab into a small café system to practise
programming concepts in a more realistic context.

## Features

- Select a valid café table
- Register customer information
- Enter products and prices
- Calculate the order subtotal
- Generate a formatted receipt

## Learning Goals

This project is being used to practise:

- User input and type conversion
- Strings and string methods
- Indexing and slicing
- F-strings and formatting
- Input validation
- Program design
- Git and GitHub workflow
